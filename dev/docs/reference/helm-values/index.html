Helm values

Values of the token-broker chart, published to oci://ghcr.io/pflege-de-labs/charts/token-broker. The authoritative list with comments is values.yaml.

Broker

ValueDefaultMeaning
replicaCount2Stateless; a second replica covers pod restarts.
image.repositoryghcr.io/pflege-de-labs/token-brokerImage.
image.tagchart appVersionImage tag.
image.pullPolicyIfNotPresent
imagePullSecrets, nameOverride, fullnameOverrideempty
serviceAccount.create, .automount, .annotations, .nametrue, false, {}, generatedThe broker never talks to the Kubernetes API.
podAnnotations, podLabels{}
podSecurityContextnon-root 65532, fsGroup: 65532, RuntimeDefault seccomp
securityContextno privilege escalation, read-only root filesystem, drop all capabilities
service.type, service.portClusterIP, 8080Serves /token, the probes and /metrics.
resources{}
livenessProbeGET /healthz
readinessProbeGET /readyz, timeoutSeconds: 5, periodSeconds: 15/readyz calls GitHub, which can take longer than 1 second.
extraEnv{}Additional environment variables.
extraObjects[]Extra manifests rendered with the release (run through tpl), for example an ExternalSecret providing existingSecret.
nodeSelector, tolerations, affinityempty

Configuration

ValueEnvironment variableDefault
config.appIdGITHUB_APP_IDrequired
config.orgGITHUB_ORGrequired
config.loginClientIdLOGIN_APP_CLIENT_IDrequired
config.apiUrlGITHUB_API_URLempty: https://api.github.com
config.agentPermissionsAGENT_PERMISSIONS{}: the default set
config.actionsOidc.audienceACTIONS_OIDC_AUDIENCEtoken-broker
config.actionsOidc.issuerACTIONS_OIDC_ISSUERempty: GitHub’s issuer
config.actionsOidc.allowedRefsACTIONS_ALLOWED_REFS[]
config.actionsOidc.allowedWorkflowsACTIONS_ALLOWED_WORKFLOWS[]

config.agentPermissions is a map, for example {contents: write, pull_requests: write, issues: write, metadata: read, actions: write}. List the full set; the agent app must be granted all of them.

Secret

ValueDefaultMeaning
existingSecretemptyName of a Secret with the keys private-key.pem and login-client-secret. When set, the chart renders no Secret and ignores secret.
secret.privateKey, secret.loginClientSecretemptyRendered into a chart-managed Secret when existingSecret is empty.

Exposure

ValueDefaultMeaning
ingress.enabledfalseDeveloper and runner access to /token. Keep it internal where possible. Also className, annotations, hosts, tls.
httpRoute.enabledfalseThe same via a Gateway API HTTPRoute. Also annotations, parentRefs, hostnames, rules.
actionsRoute.enabledfalsePublic route for GitHub-hosted runners: forwards only POST <path> to /token/actions. Needs parentRefs (an internet-facing Gateway).
actionsRoute.path/token/actionsPublic path, rewritten to /token/actions; set a prefix when the host is shared.
actionsRoute.hostnames, .annotations, .labelsempty

metrics.serviceMonitor.interval, .scrapeTimeoutempty
metrics.serviceMonitor.extraLabels, .annotations{}
metrics.serviceMonitor.relabelings, .metricRelabelings[]
